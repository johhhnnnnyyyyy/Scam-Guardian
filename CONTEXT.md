# Domain glossary

- Senior: person using the listening aid.
- Guardian: trusted family member explicitly allowed to receive alerts.
- Session: one user-started listening or analysis period.
- Tactic: an observed pressure behavior, not a declaration of criminal guilt.
- Evidence: an exact transcript quote supporting a tactic.
- Risk level: suggested protective action based on detected evidence.
- Evidence pack: user-exported record of the analysis, not an official complaint.
- Synthetic demo: authored fictitious conversation; not evidence of microphone or provider performance.
- Profile: short-lived local capability that carries language and a bounded reason-only warning timeline across sessions; not a verified identity.
- Pairing: senior-approved, expiring session capability for a family member's reason-only view.
- Code word: a family-chosen secret communicated directly to the senior; the app stores only a configured flag and prompts on a claimed family emergency.
- Cooling-off: advice to pause ten minutes after a payment request plus amount; never a payment block.
- Provider-verified: a real credentialed cloud response has been observed and checked. Mock-based tests alone do not satisfy this term.
- Locally implemented: code and local tests exist; this alone does not prove correct behavior on a phone or with a real caller.
- Device-verified: tested on a physical listening/playback device through its actual browser, audio route, permissions and network conditions. This has not yet been achieved for this MVP.
- Publicly deployable: identity, HTTPS, abuse controls, operational and privacy/legal gates are closed. The current local MVP does not meet this definition.
